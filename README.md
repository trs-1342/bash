# SHELL/BASH
bu repoda linux sistemini daha iyi anlamam icin shell/bash ogrendiklerim iceriyor.

## echo
- ekrana yazi yazdirmak icin kullanilir.

## read
- kullanicidan deger almak icin kullanilir.

## degiskenler
- $ ile tanimlanirlar, sabit degiskenler buyuk harflerle yazilir.
- tanimlamak veya yazdirmak icin baslarina $ isareti konulur, ornekler:
- `$AD`, `$SOYAD`, `$ftp_file='/root/etc/ftp.py'`
